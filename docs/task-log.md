# 작업 로그

에이전트는 세션 시작 시 이 파일부터 읽고, 맨 위의 `todo` 작업을 집는다.
상태: `todo` → `doing` → `done`. 완료 시 시간·게이트 실패·수동 수정 줄 수를 적는다.

**병렬 규칙**: `모듈` 열이 겹치지 않는 `todo`만 동시에 진행. `선행`이 `done`이 아니면 시작 금지.
`통합` 표시 작업은 공유 파일을 바꾸므로 항상 혼자 돈다.
